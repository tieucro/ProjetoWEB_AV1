# Projeto Web — AV1

Atividade de Programação Web do curso de Análise e Desenvolvimento de Sistemas. O site reúne quatro exercícios acessíveis pelo menu **Questões**.

| Página | Exercício |
| --- | --- |
| [Questão 1](questao1.html) | Cálculo de média escolar |
| [Questão 2](questao2.html) | Formulário de carnê de pagamento |
| [Questão 3](questao3.html) | Formulário de contracheque |
| [Questão 4](questao4.html) | Cálculo de IMC |

## Tecnologias

HTML, JavaScript e Bootstrap 4. O menu usa jQuery e Popper.js.

## Como abrir

Abra [`index.html`](index.html) no navegador e use o menu **Questões**. A página carrega o Bootstrap e as bibliotecas do menu por CDN.
